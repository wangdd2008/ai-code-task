# Translate Docs

将指定目录下的 Markdown 文档批量从英文翻译为中文，覆盖原始文件，保留文档内部关联链接。

## 触发条件

- 用户说"把目录下所有 Markdown 文档翻译成中文"
- 用户说"翻译这个目录下的文档"
- 用户上传了一个包含英文 Markdown 文档的目录，要求翻译
- 用户说"将 v1.x.x 全部翻译为中文"
- 用户说"批量翻译 Markdown 文档"

## 标准流程

### 1. 扫描目录

扫描指定目录下的所有 `.md` 文件，列出待翻译文件清单：

```powershell
Get-ChildItem -Path "<target-dir>" -Filter "*.md" -Recurse
```

### 2. 读取文件内容

逐个读取每个 `.md` 文件的内容。使用 `read_file` 工具获取完整内容。

### 3. 翻译文件

对每个文件执行以下翻译规则：

#### 3.1 保留不变的内容
- **文件名**：保持不变，确保文档内部链接自然保留
- **代码块**（``` 包裹的内容）：原样保留，不翻译
- **命令行示例**（`$` 或 `>` 开头的行）：原样保留
- **URL 链接**：原样保留
- **文件名/路径引用**：如 `customization.md`、`openspec/config.yaml` 等，原样保留
- **技术术语**：如 `spec-driven`、`camelCase`、`snake_case` 等，保留英文原词
- **RFC 2119 关键字**：`MUST`、`SHALL`、`SHOULD`、`MAY`、`REQUIRED`、`OPTIONAL` 等保留英文，但在首次出现时补充中文解释

#### 3.2 需要翻译的内容
- **标题**（`#`、`##`、`###` 等）：翻译为中文
- **正文段落**：翻译为通顺、自然的中文
- **表格内容**：翻译表头和相关描述文本
- **列表项**：翻译列表描述
- **引用块**（`>` 开头）：翻译引用内容
- **提示/警告块**（如 `> **Note**`）：翻译提示内容

#### 3.3 特殊处理
- **内部文档链接**：保持原样，如 `[Customization](customization.md)`
- **锚点链接**：保持原样，如 `[Overview](#overview)`
- **Mermaid 图表中的文本**：翻译图表中的描述文字
- **ASCII 艺术/示意图**：保留结构，翻译其中的文字标注

### 4. 写入翻译后的文件

使用 `create_file` 工具覆盖写入翻译后的内容。确保：
- 文件路径与原始文件一致
- 文件编码为 UTF-8
- 保留原始的 Markdown 格式和结构

### 5. 验证

翻译完成后，检查以下内容：
- 所有 `.md` 文件是否都已翻译
- 文档内部链接是否仍可正常访问（文件名未变）
- 代码块和命令示例是否未被破坏
- YAML frontmatter（如果有）是否保留原样

## 翻译质量规范

1. **术语一致性**：相同术语在整个文档集中保持统一翻译
2. **技术准确性**：技术概念翻译准确，不引起歧义
3. **流畅自然**：中文表达通顺，符合技术文档写作习惯
4. **格式保留**：Markdown 格式、表格、列表结构完整保留
5. **链接保留**：所有内部链接、外部链接原样保留

## 常见术语翻译对照

| 英文术语 | 中文翻译 |
|---------|---------|
| Spec / Specification | 规格 / 规格说明 |
| Proposal | 提案 |
| Design | 设计 |
| Tasks | 任务 |
| Change | 变更 |
| Archive | 归档 |
| Workflow | 工作流 |
| Schema | 模式 |
| Artifact | 产物 |
| Store | 存储 / Store（专有名词可保留英文） |
| Workset | 工作集 |
| Context | 上下文 |
| CLI | CLI（保留英文） |
| Configuration | 配置 |
| Customization | 自定义 |
| Validation | 验证 |
| Delta | 差异（Delta Specs = 差异规格） |
| Proposal | 提案 |
| Review | 审查 |
| Apply | 应用 / 实现 |
| Sync | 同步 |
| Explore | 探索 |

## 示例

**场景**：用户要求翻译 `src/002-open-source-docs/Fission-AI-OpenSpec/v1.13.2/` 目录下所有文档

```
1. 扫描目录 → 发现 27 个 .md 文件
2. 逐个读取文件内容
3. 对每个文件执行翻译，覆盖写入
4. 验证所有文件已翻译，内部链接保留
5. 报告完成状态
```

## 注意事项

- 翻译前确认目标目录的所有 `.md` 文件都已列出，不要遗漏
- 对于超过 1000 行的文件，可能需要分段读取和翻译
- 翻译过程中遇到不确定的技术术语，保留英文原词
- 原始文档中的 YAML frontmatter（如 `---
name: xxx
---`）应原样保留
- 如果文档包含 HTML 标签，保留标签结构，翻译标签内的文本
- 翻译后的文件直接覆盖原文件，不创建备份
