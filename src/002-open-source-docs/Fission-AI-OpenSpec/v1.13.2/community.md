# 社区展示

一个由社区维护的精彩列表，展示使用和支持 OpenSpec 构建的项目和资源。欢迎提交工具、集成、工作流和学习资源。社区成员通过拉取请求来增长和维护这个展示。

列出的项目独立维护。列入其中并不意味着 OpenSpec 的官方支持或认可。请参阅每个项目的文档和问题追踪器以获取设置和支持。

## 项目和资源

- **[OpenSpec Workbench](https://github.com/VeryComplexAndLongName/OpenSpec-UI)**: 运行和监督基于 OpenSpec 变更的 Agent。
- **[MySpec](https://myspec.dev)**: 云测试版（需要账户），进行引导式规格访谈并导出四文件包或 OpenSpec 兼容变更。该服务将提交内容发送给第三方 AI 提供商，不适用于敏感数据。
- **[openspec-guard](https://github.com/guillaume-flambard/spec-guard)**: CLI 和 GitHub Action，报告哪些 OpenSpec 场景已被 Vitest 或 Jest 测试覆盖，而无需运行测试。

## 添加你的项目

打开一个拉取请求，在此文件中添加一行，包含你的项目名称、直接链接以及简短描述，说明它与 OpenSpec 的关系。

- 保持条目专注于使用 OpenSpec 构建或支持其使用的内容，而非一般产品广告。
- 描述人们可以使用什么。避免宣传性声明、推荐链接和追踪链接。
- 如有付费功能或需要账户，请在条目中披露。

对现有条目的更正和更新同样欢迎。
