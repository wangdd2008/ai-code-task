# 分类标签

这些技能使用五个标准的分类角色。本文件将角色映射到本仓库问题追踪器中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们的追踪器中的标签 | 含义                                   |
| -------------------------- | -------------------- | -------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估此问题                   |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息                 |
| `ready-for-agent`          | `ready-for-agent`    | 已完全说明，可供 AFK 代理处理          |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现                           |
| `wontfix`                  | `wontfix`            | 不会处理                               |

当技能提到某个角色时（例如"应用 AFK-ready 分类标签"），请使用上表中的对应标签字符串。

在确定状态前，请针对每个问题对照 [`SCOPE.md`](../../SCOPE.md) 进行评估。拒绝的问题将标记为"not planned"（不计划处理）。
